# Java

## Verificando instalação

```bash
java -version
javac -version
```

## Compilação

```bash
javac Main.java
```

## Execução

```bash
java Main
```

## Compilando vários arquivos

```bash
javac *.java
```

## Executando um pacote

```bash
java pacote.Main
```

## Arquivos JAR

Criar:

```bash
jar cf projeto.jar *.class
```

Executar:

```bash
java -jar projeto.jar
```
